# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) instead and include:

- a description of the issue and its impact,
- steps to reproduce,
- the firmware version (*Settings → About*) and board variant.

You will receive an answer as soon as possible. Once a fix is available, the report can be published together with
the release notes.

Note that CarCYD is a display and diagnostics front end: it must never be the only means of monitoring safety
relevant vehicle functions.
